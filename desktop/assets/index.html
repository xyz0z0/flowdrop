网络绑定

选择 Hub 监听的具体本机 IPv4 地址（不监听 0.0.0.0）。单地址是旧方式； 需要手机在家用 Wi-Fi 和 Tailscale 下都能直接访问时，选择「同时使用内网和 Tailscale」， 同一个 Hub 会在两个地址的同一端口上提供服务，数据与登录完全共享。

在这个列表中选择一个要绑定的地址：

未检测到 Tailscale 网卡：不能选择双模式，但仍可使用内网单地址模式正常收发。 跨网络访问需要你在系统里自行安装并登录 Tailscale；本应用不会要求或自动安装它。

两处必须是本机当前真实存在的地址，且不能相同。保存后 Hub 会同时绑定这两个 IP 的同一端口； 任一地址绑定失败则整体失败并恢复原配置，不会只启动一半。

更换地址/端口会先停止旧 Hub（撤回 mDNS、释放全部端口），再以同一数据目录启动新实例。 若新地址失效、端口被占用或只绑定成功一部分，会明确报错并自动尝试恢复原配置。
