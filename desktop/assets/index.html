运行模式

默认由这台电脑启动 Hub。也可以连接另一台机器（局域网或 Tailscale）上已经在运行的 Hub， 这时本机不会再启动自己的 Hub。保存后立即生效，不需要重启 FlowDrop。

填局域网或 Tailscale 地址，不含路径；配对在收件箱页里输入该 Hub 生成的 4 位码。 对端在 Tailscale 上时请填它的 100.x 地址；两台机器都用 192.168.x.x 但不在同一局域网时，LAN 地址不可达。

    网络绑定

    选择 Hub 监听的具体本机 IPv4 地址（不监听 0.0.0.0）。 需要手机在家用 Wi-Fi 和 Tailscale 下都能直接访问时，选择「同时使用内网和 Tailscale」， 同一个 Hub 会在两个地址的同一端口上提供服务，数据与登录完全共享。

    在这个列表中选择一个要绑定的地址：

    未检测到 Tailscale 网卡：不能选择双模式，但仍可使用内网单地址模式正常收发。 跨网络访问需要你在系统里自行安装并登录 Tailscale；本应用不会要求或自动安装它。

    两处必须是本机当前真实存在的地址，且不能相同。保存后 Hub 会同时绑定这两个 IP 的同一端口； 任一地址绑定失败则整体失败并恢复原配置，不会只启动一半。

    勾选后不需要再选地址：Hub 会在这个端口上绑定本机当前所有可用的局域网和 Tailscale 地址， 网络变化（例如换 Wi-Fi 或连上 Tailscale）后会自动跟上，不用重启。
